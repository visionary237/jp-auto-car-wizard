# AUTO EXPRESS 76 — site vitrine 360°

Démo du site du garage AUTO EXPRESS 76 (Le Havre), conçu par **DOERZ**.

- Hero : véhicule photoréaliste à 360° piloté au scroll (séquence de 122 images nettoyées par IA)
- « Montrez-nous où » : la voiture se tourne au doigt ou à la souris, zones cliquables, zoom sur la pièce, fiche d'intervention
- Prestations en galerie horizontale, 10 pages de services
- Stack : TanStack Start (React), GSAP + ScrollTrigger, Tailwind CSS

Ce dépôt contient la version compilée, publiée avec GitHub Pages.
